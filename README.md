# Halcyon Solver

**Status:** Released (public) — v1.2.0 (first public release 2025-06-14).

Reference implementation of cascade error bounds for sketch-and-project solvers, including the row/column sketch harness used in the paper.

## Repository layout

- `src/` — core library and reference implementation
- `data/` — released data cards and benchmark splits
- `experiments/` — scripts that reproduce the paper's tables and figures
- `configs/` — experiment configurations

## Citation

P. Carter, N. Okafor, L. Brennan. Cascade Error Bounds for Sketch-and-Project Solvers. SIAM J. Matrix Anal. Appl., 2025.
